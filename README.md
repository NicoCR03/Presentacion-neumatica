# Sistemas neumáticos

Presentación de Nicolás Donoso Calvo, C22625, para Sistemas Automatizados de Manufactura.

22 diapositivas con animaciones. Abrir index.html o publicar esta carpeta en GitHub Pages desde la rama main y la carpeta raíz.

Usar las flechas para navegar y los botones de las diapositivas para las demostraciones. Las referencias se encuentran al final.

Para descargar la presentación en PDF, pulsa Descargar PDF y selecciona Guardar como PDF como destino. Se exportan las 22 diapositivas sin animaciones.
